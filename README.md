Автор: Baxamyt Studio
Дата сборки: 2026-10-04

## Что нового
- Раздел «Плагины» (в разработке); «Настройки» всегда внизу бокового меню.
- Колокольчик уведомлений: 5 последних в выпадающей панели, остальные в файле, бейдж со счётчиком, анимация, переключатель в настройках, проверка каждые 60 секунд.
- Автозапуск вместе с Windows (переключатель в настройках).
- Выбор пути для движка Vexa (по умолчанию LOCALAPPDATA\Vexa\Engine, можно изменить).
- Новая иконка Vexa Gold.
- Красивый стилизованный скролл в окне просмотра; кнопка «Копировать» текст.

## Что исправлено
- Выровнена синяя полоса сверху карточек (клип по скруглённому контуру).
- Иконки в настройках без подписей.
- URL обновления: .../releases/latest/download/Update.zip.

## Сборка
Запустите build.bat (нужен установленный MinGW-w64 g++). Антивирус может ругаться на самодельный .exe — это ложное срабатывание.

## Ограничения
- Иконка .exe на рабочем столе вшита в PE и не меняется в рантайме.
- Сборка в среде агента не выполнялась (нет компилятора/сети) — проверьте локально.
