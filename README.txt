============================================================
  Vexa  (движок: Vexa Engine)
  Настольное приложение на C++ (Win32 + GDI+)
  Разработчик: Baxamyt Studio
============================================================

Что нового в этой версии
----------------------
  • Новый тёмный дизайн в стально-синих тонах.
  • Новая иконка (в окне и на панели задач).
  • Полная локализация: Русский / English (переключатель в Настройках).
  • Вкладка "Загрузки" с прогресс-баром (%, файл, статус).
  • Автопроверка обновлений и кнопка "Обновление" (снизу слева).
  • Новости на главной (клик по блоку открывает полный текст).

Управление
----------
  • Кнопки справа сверху — свернуть, развернуть, закрыть
  • Боковое меню: Главная, Движок, Проект, Загрузки, Настройки
  • Двойной клик по верхней панели — развернуть/вернуть
  • Перетаскивание — за верхнюю панель
  • ESC — закрыть окно чтения / выход

Разделы Движок / Проект пока показывают "Раздел в разработке".

Сборка
------
Дважды кликните по build.bat. Он соберёт:
  Vexa.exe  и  VexaUpdater.exe  (+ встроит иконку).
Если компилятора нет — скрипт сам скачает MinGW-w64 (нужен интернет).

Для работы рядом должны лежать:
  Vexa.exe, VexaUpdater.exe, version.json  (и желательно app.ico).

Обновления через GitHub
----------------------
Подробная пошаговая инструкция — в файле:
  ИНСТРУКЦИЯ_ОБНОВЛЕНИЯ.txt

Файлы в архиве
--------------
  main.cpp                   — исходный код приложения
  VexaUpdater.cpp            — исходный код апдейтера
  app.rc / app.ico           — иконка
  version.json               — локальный номер версии
  build.bat                  — автосборка
  ИНСТРУКЦИЯ_ОБНОВЛЕНИЯ.txt   — как выпускать обновления
  README.txt                 — этот файл

Примечание: реальная сборка exe в среде разработки не проверялась —
соберите у себя через build.bat и проверьте работу.
