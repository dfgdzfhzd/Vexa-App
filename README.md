## Vexa Engine 1.0.0

**Vexa Engine** — это собственный игровой движок и редактор от Baxamyt Studio, который
поставляется вместе с лаунчером Vexa. Движок запускается как отдельное
приложение `VexaEngine.exe` и не зависит от лаунчера: закрытие Vexa не
закрывает редактор.

### Что это

Лёгкий движок на C++17 для Windows (Win32 + OpenGL для Viewport и GDI+ для
панелей редактора). Поддерживает проекты трёх типов: 2D, 3D и WEB.
Собирается в один исполняемый файл без внешних зависимостей.

### Основные функции

- **Редактор из 4 зон:** Viewport (сцена), Hierarchy (дерево объектов),
  Inspector (свойства) и Console/Assets (журнал и ресурсы).
- **Сцена и объекты:** дерево Entity, добавление/удаление, трансформации,
  сериализация сцены в JSON.
- **Менеджер ресурсов (AssetManager):** асинхронная загрузка с пулом
  потоков, кэш и статусы.
- **Рендер OpenGL:** собственный WGL-контекст для отрисовки Viewport.
- **Чёткий игровой цикл:** ProcessInput -> FixedUpdate (60 Гц) -> Update(dt) -> Render.
- **Формат проекта `.vexa`:** простой JSON с именем, типом и версией;
  создаётся лаунчером автоматически.

### Инструменты редактора

- Вращение камеры и выбор объектов мышью, горячие клавиши редактора.
- Создание, удаление и переименование объектов сцены.
- Импорт ресурсов (модели, текстуры, аудио) с отслеживанием статуса.
- Сохранение и загрузка проекта и сцены.
- Полное описание — в `engine/docs/ENGINE_TOOLS.md`.

### MCP-инструменты

Движок предоставляет программный интерфейс MCP (Model Context Protocol):
внешний клиент (ИИ-ассистент или скрипт) может управлять сценой и
проектом командами 
`scene.read/write`, 
`entity.create/delete/rename`,
`asset.import`, 
`project.open/save`, 
`log.write` и др. 
Полная схема — в `engine/docs/ENGINE_TOOLS.md` (раздел 8).

### Сборка

Скрипт `engine/build.bat` собирает `VexaEngine.exe`. Требуется MinGW-w64
(g++): скрипт сначала ищет его в PATH, затем в `..\mingw64\bin` и
`engine\mingw64\bin`.
